# Direct Media is a Lynvo plugin

Direct Media uses the Plugin Server Protocol and runs on the Lynvo Plugin
Server. Lynvo Core does not probe media URLs or maintain a second extraction
path. Explicit selection, configured Plugin Domains, and static matches take
precedence; the Direct Media capability probe runs after them. This gives
routing, allowance accounting, capacity control, errors, observability, and
saved-link affinity one managed-extraction path.
