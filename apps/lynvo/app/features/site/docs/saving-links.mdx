## Overview

Save a Source URL to create a Saved link. Lynvo runs Extraction for the URL, stores the returned Media Nodes, and keeps the Saved link in your Library.

</DocSection>

<DocSection id="configure">

## Configure

Open [**Settings > General**](/settings/general) and choose whether Lynvo saves every playable choice automatically or asks you to select links. You can change this preference later; see [General settings](/docs/general).

</DocSection>

<DocSection id="basics">

## Basics

### Save a URL

1. Open [Save](/save).
2. Paste or type the Source URL into **Link**.
3. Choose **Save link** or press Enter.

Lynvo may offer a copied URL above the field. Choose **Enable clipboard suggestions**, then **Allow clipboard access**, if you want Lynvo to read the clipboard and offer a copied link. Nothing is saved until you choose to save it.

If the URL is already in your Library, Lynvo shows **Link already saved**. Open the existing Saved link instead of adding a duplicate.

### Choose links to save

When automatic saving is off, Lynvo keeps the Save intent in your Library while Extraction runs. When links are ready, choose **Choose links**, select the Playable links you want, then choose **Save**. **Select all** toggles every selectable link. **Cancel** closes the dialog without confirming a new selection; reopen **Choose links** to continue.

### Follow Extraction status

A Saved link can show **Waiting to load…** while Extraction is queued, then **Loading links…** while it runs. If it fails, Lynvo shows the returned error and offers **Delete** and **View log**. Open the item menu and choose **Refresh** to try Extraction again. The log helps distinguish a Source response problem from a link-selection problem.

### Read Source status

During save, a Source status can explain why results are delayed or incomplete:

- **Maintenance** means the Source is undergoing maintenance and some links may be unavailable.
- **Degraded** means the Source is responding slowly and some links may be unavailable.
- **Unavailable** means the Source is temporarily unavailable; try again later.

### Add a Plugin Domain suggestion

After Lynvo recognizes a domain handled by a Plugin, it may ask **Add this domain for faster loading?** Choose **Add domain** to use that Plugin for the site next time, or **Not now** to dismiss the suggestion. You can manage Plugin Domains later in [**Settings > Plugins**](/settings/plugins).

### Resolve URL and selection errors

| Message                                                                                     | What to do                                                                            |
| ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| **Enter a URL.**                                                                            | Enter a Source URL.                                                                   |
| **Enter a valid URL.**                                                                      | Check the address, then try again.                                                    |
| **Select at least one link.**                                                               | Select a Playable link before saving.                                                 |
| **Link already saved**                                                                      | Open the existing Saved link.                                                         |
| **Link not supported**: “The link is not supported.”                                        | Check that the URL is complete and points to a supported Source or Direct Media link. |
| **Link couldn’t be opened**: “The link couldn’t be opened. Check the link, then try again.” | Check the URL and try again.                                                          |

### Recover from Extraction errors

| Message                                                                              | What to do                                          |
| ------------------------------------------------------------------------------------ | --------------------------------------------------- |
| “Links couldn’t be loaded from this address. Check the link, then try again.”        | Check the Source URL.                               |
| “The session expired. Sign in, then save the link again.”                            | Sign in and save the link again.                    |
| “The session expired. Sign in, then try again.”                                      | Sign in and retry.                                  |
| “Extraction is temporarily unavailable. Try again in a moment.”                      | Wait, then refresh the Saved link.                  |
| “Extraction is rate-limited. Wait a moment, then try again.”                         | Wait, then refresh the Saved link.                  |
| “The Plugin Server is unavailable. Try again later or choose another Plugin Server.” | Wait or choose another Plugin Server, then refresh. |

### Retry failed saves

| Message                                                                      | What to do                                   |
| ---------------------------------------------------------------------------- | -------------------------------------------- |
| “Unable to save link. Try again.”                                            | Retry the save.                              |
| “Unable to save selected links. Try again.”                                  | Reopen the dialog and retry the selection.   |
| “Unable to save the selected links. Try again.”                              | Reopen the dialog and retry the selection.   |
| “Account storage is full. Remove a saved link, then try again.”              | Remove a Saved link, then retry.             |
| “This saved link is too large. Remove some extracted items, then try again.” | Choose fewer items, then retry.              |
| “The signed-in account changed. Try again from the current account.”         | Continue with the current account and retry. |
| “The security session expired. Refresh the page, then try again.”            | Refresh the page, then retry.                |
| “The link couldn’t be saved right now. Try again.”                           | Retry the save.                              |

<DocSection id="faq">

## FAQ

<DocsFaq question="Can I close Choose links and return later?">
  Yes. **Cancel** closes the selection dialog without confirming the selection.
  The Saved link remains in your Library, and you can reopen **Choose links**
  when you are ready.
</DocsFaq>

<DocsFaq question="What should I do when Extraction fails?">
  Match the message under [Recover from Extraction
  errors](#recover-from-extraction-errors), use **View log** for details, then
  choose **Refresh** to retry. Choose **Delete** if you no longer want the Saved
  link.
</DocsFaq>
