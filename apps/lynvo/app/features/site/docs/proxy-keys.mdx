## Overview

A proxy key lets a supported Custom Plugin Server use a Scrape.do account for proxy requests instead of its shared proxy credits. Each server keeps its own key and proxy switch. Lynvo stores the key encrypted and sends it only to that server during Extraction when its proxy switch is on.

</DocSection>

<DocSection id="configure">

## Configure

Open [**Settings > Proxy**](/settings/proxy). Only Custom Plugin Servers that declare Scrape.do support appear here. The Lynvo Plugin Server is not eligible for a user proxy key.

</DocSection>

<DocSection id="basics">

## Basics

### Read monthly credit usage

Each supported server shows the monthly credit usage for its saved key, including the percentage used and when Lynvo last checked it. Choose that server’s **Refresh credits** action to check the key again. The **Use proxy** switch applies only to the server named on that row.

### Add or change a proxy key

1. In the server’s **Scrape.do** row, choose **Add key** to open the key dialog.
2. Enter your token in **Scrape.do API token**.
3. Choose **Save key**.

Lynvo encrypts the key for storage. It does not send the key to the browser in server settings data. A key change affects only the server whose row you used and does not change its proxy switch.

The Scrape.do row shows whether a key is saved for that server. Choose **Change key** to replace it or the trash button to remove it. These controls apply only to the server on the same card. Closing the dialog without saving leaves a saved value unchanged.

### Choose when to use the key

Each supported server's switch has three states:

- No key is saved: the switch is off and disabled. Add a key before turning it on.
- A key is saved and the switch is off: Extractions use the Custom Plugin Server's own proxy behavior.
- A key is saved and the switch is on: that server can use your Scrape.do credits for Extractions.

If the server is unavailable, Lynvo disables the switch until it is available again. Turning the switch off keeps the key. Remove the key when you no longer want Lynvo to retain it.

## FAQ

<DocsFaq question="Why is there no Custom Plugin Server on this page?">
Only servers whose manifest declares Scrape.do proxy support appear in **Settings > Proxy**. Connect a compatible Custom Plugin Server in [**Settings > Plugins**](/settings/plugins).
</DocsFaq>

<DocsFaq question="Does turning a server's proxy switch off remove my token?">
  No. The switch controls whether Lynvo sends the saved token to that server
  during Extraction. Choose **Remove key** on that server’s row to remove it.
</DocsFaq>

<DocsFaq question="Why can’t I refresh credits?">
  Add a key before refreshing. If a saved key cannot be checked, Lynvo shows an
  error toast; confirm the token, then choose **Refresh credits** again.
</DocsFaq>
