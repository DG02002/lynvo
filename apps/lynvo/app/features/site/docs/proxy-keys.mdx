## Overview

A proxy key lets a supported Custom Plugin Server use your Scrape.do account for proxy requests instead of its shared proxy credits. Lynvo stores the key encrypted and sends it only to that server during Extraction when its proxy switch is on.

</DocSection>

<DocSection id="configure">

## Configure

Open [**Settings > Proxy**](/settings/proxy). Only Custom Plugin Servers that declare Scrape.do support appear here. The Lynvo Plugin Server is not eligible for a user proxy key.

</DocSection>

<DocSection id="basics">

## Basics

### Read monthly credit usage

Under the Scrape.do logo, **Monthly credit usage** shows how many of your credits are used, the percentage used, and when Lynvo last checked your account. Choose **Refresh credits** to check the account again. Servers that support Scrape.do appear below, each with a switch that turns proxy use on or off for that server.

### Add or change a proxy key

1. Choose the **+** next to the Scrape.do logo to open the key dialog.
2. Enter your token in **Scrape.do API token**.
3. Choose **Save key**.

Lynvo encrypts the key for storage. It does not send the key to the browser in server settings data. Saving a key also turns proxy use on for every supported server, so Extractions can use your credits right away.

Choose the trash button next to the Scrape.do logo to delete the stored key. Closing the dialog without saving leaves a saved value unchanged.

### Choose when to use the key

Each supported server's switch has three states:

- No key is saved: the switch is off and disabled. Add a key before turning it on.
- A key is saved and the switch is off: Extractions use the Custom Plugin Server's own proxy behavior.
- A key is saved and the switch is on: that server can use your Scrape.do credits for Extractions.

If the server is unavailable, Lynvo disables the switch until it is available again. Turning the switch off keeps the key. Remove the key with the trash button when you no longer want Lynvo to retain it.

<DocSection id="faq">

## FAQ

<DocsFaq question="Why is there no Custom Plugin Server on this page?">
Only servers whose manifest declares Scrape.do proxy support appear in **Settings > Proxy**. Connect a compatible Custom Plugin Server in [**Settings > Plugins**](/settings/plugins).
</DocsFaq>

<DocsFaq question="Does turning a server's proxy switch off remove my token?">
  No. The switch controls whether Lynvo sends the saved token to that server
  during Extraction. Use the trash button next to the Scrape.do logo to remove
  it.
</DocsFaq>

<DocsFaq question="Why can’t I refresh credits?">
  Add a key before refreshing. If a saved key cannot be checked, Lynvo shows an
  error toast; confirm the token, then choose **Refresh credits** again.
</DocsFaq>
