## Overview

A proxy key lets supported Custom Plugin Servers use your Scrape.do account for proxy requests instead of their shared proxy credits. You save one Scrape.do key for your Lynvo account, then choose per server whether it may use that key. Lynvo stores the key encrypted and sends it only to servers whose proxy switch is on.

</DocSection>

<DocSection id="configure">

## Configure

Open [**Settings > Proxy**](/settings/proxy). The page has two parts: the **Proxy providers** card for your Scrape.do key, and the **Servers** list for choosing which servers use it. Only Custom Plugin Servers that declare Scrape.do support appear in the list. The Lynvo Plugin Server is not eligible for a user proxy key.

</DocSection>

<DocSection id="basics">

## Basics

### Add or change the proxy key

1. In the **Scrape.do** card, choose **+** to open the key dialog.
2. Enter your token in **Scrape.do API token**.
3. Choose **Save key**.

Lynvo validates the token, encrypts it for storage, and shows the account's monthly credit usage on the same card. It does not send the key to the browser in settings data. Open the Scrape.do key actions menu to choose **Change key** or **Remove key**. Closing the dialog without saving leaves a saved value unchanged.

### Read monthly credit usage

The Scrape.do card shows the monthly credit usage for the saved key, including the percentage used and when Lynvo last checked it. Choose **Refresh credits** to check the key again.

### Choose which servers use the key

Each supported server has a **Use proxy** switch with three states:

- No key is saved: every switch is off and disabled. Add a key before turning one on.
- A key is saved and a switch is off: Extractions through that server use its own proxy behavior.
- A key is saved and a switch is on: that server can use your Scrape.do credits for Extractions.

If a server is unavailable, Lynvo disables its switch until it is available again. Turning a switch off keeps the key. Remove the key when you no longer want Lynvo to retain it.

## FAQ

<DocsFaq question="Why is there no Custom Plugin Server in the Servers list?">
Only servers whose manifest declares Scrape.do proxy support appear in **Settings > Proxy**. Connect a compatible Custom Plugin Server in [**Settings > Plugins**](/settings/plugins).
</DocsFaq>

<DocsFaq question="Does turning a server's proxy switch off remove my token?">
  No. The switch controls whether Lynvo sends the saved key to that server
  during Extraction. Choose **Remove key** from the Scrape.do key actions menu
  to remove the key for your whole account.
</DocsFaq>

<DocsFaq question="Why can’t I refresh credits?">
  Add a key before refreshing. If a saved key cannot be checked, Lynvo shows an
  error toast; confirm the token, then choose **Refresh credits** again.
</DocsFaq>
