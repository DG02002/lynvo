## Overview

A proxy key lets a supported Custom Plugin Server use your Scrape.do account for proxy requests instead of its shared proxy credits. Lynvo stores the key encrypted and sends it only to that server during Extraction when **Use proxy key** is on.

</DocSection>

<DocSection id="configure">

## Configure

Open [**Settings > Proxy**](/settings/proxy). Only Custom Plugin Servers that declare Scrape.do support appear here. The Lynvo Plugin Server is not eligible for a user proxy key.

</DocSection>

<DocSection id="basics">

## Basics

### Add or change a proxy key

1. Choose **Add proxy key** for a server, or **Change key** if it already has one.
2. Enter your token in **Scrape.do API token**.
3. Choose **Save key**.

Lynvo encrypts the key for storage. It does not send the key to the browser in server settings data. During Extraction, Lynvo sends it only to the matching Custom Plugin Server when proxy use is enabled; that server can then use your Scrape.do account.

Choose **Remove saved key** in the dialog if you want Lynvo to delete the stored key. Closing the dialog without saving leaves the saved value unchanged.

### Choose when to use the key

**Use proxy key** has three states:

- No key is saved: the switch is off and disabled. Add a key before turning it on.
- A key is saved and the switch is off: Extractions use the Custom Plugin Server's own proxy behavior.
- A key is saved and the switch is on: that server can use your Scrape.do credits for Extractions.

If the server is unavailable, Lynvo disables the switch until it is available again. Turning the switch off keeps the key. Remove the key separately when you no longer want Lynvo to retain it.

### Check balance and per-Plugin usage

The **Balance** row shows **Not checked yet** until Lynvo reads your account balance. After a check, it shows remaining credits and the account limit, plus when Lynvo last checked. Choose **Refresh balance** to check again. The **Proxy usage** rows show usage hints supplied by each Plugin for its Extractions.

<DocSection id="faq">

## FAQ

<DocsFaq question="Why is there no Custom Plugin Server on this page?">
Only servers whose manifest declares Scrape.do proxy support appear in **Settings > Proxy**. Connect a compatible Custom Plugin Server in [**Settings > Plugins**](/settings/plugins).
</DocsFaq>

<DocsFaq question="Does turning off Use proxy key remove my token?">
  No. The switch controls whether Lynvo sends the saved token to that server
  during Extraction. Choose **Change key**, then **Remove saved key** to remove
  it.
</DocsFaq>

<DocsFaq question="Why can’t I refresh the balance?">
  Add a key before refreshing. If a saved key cannot be checked, Lynvo shows an
  error toast; confirm the token, then choose **Refresh balance** again.
</DocsFaq>
