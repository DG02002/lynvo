## Overview

Your Library contains the Saved links you chose. List view shows each Saved link in a row; Gallery view groups related Saved links with Artwork.

</DocSection>

<DocSection id="configure">

## Configure

Choose a view in [**Settings > General**](/settings/general), under **Saved links view**:

| Option           | Description                            | Availability                                                  |
| ---------------- | -------------------------------------- | ------------------------------------------------------------- |
| **List view**    | “Browse every saved link in rows.”     | Available on supported browsers.                              |
| **Gallery view** | “Group movies and shows with artwork.” | Available on supported browsers. Gallery view is the default. |

The radio cards show a preview of each layout. Your selection controls how the Library appears on signed-in sessions that use that preference.

</DocSection>

<DocSection id="basics">

## Basics

### Browse Saved links in List view

List view shows Saved links in rows, grouped under **Today**, weekday names, and **Older**. Each row can show its title, New or opened state, and a Playable link's expiry when one is known.

### Browse related links in Gallery view

Gallery view groups related movies and shows with posters and Artwork. A show can be grouped by Season and Episode, with poster or episode-still Artwork. Choose a group to browse its contents; the page shows the work's clear logo and genres under the poster when the metadata source has them, and the title otherwise. **Show episode names** changes whether episode names appear in the gallery. Choose **Change artwork** on a Library card to select different Artwork for its group. Touch-and-hold a Saved link or Gallery group to open its menu. A group menu offers **Delete all**, which removes every Saved link in the group without opening it.

### Open a Saved link menu

Open the item menu for actions that depend on the selected Saved link:

- **Copy Source link** copies the original URL you saved.
- **Report issue** opens a report with the Request ID and Extraction details prefilled, ready to send to GitHub or Telegram. You can edit the message before sending.
- **Refresh** runs Extraction again. When automatic saving is off, it appears as **Refresh link choices** because the new choices need your selection. Direct Media links are their own playable link, so their menu offers no refresh.
- **Open in** lets you choose a supported Android player for this open.
- **Remove saved link** removes the Saved link from your Library; you can save it again from the Source URL.
- In Gallery view, a Library card's menu offers **Change artwork**, which opens the artwork chooser, already searching for the title Lynvo parsed from the link. When several works share a name, such as remakes in different years, Lynvo asks you to pick instead of guessing.

### Read expiry and opened states

**New** means a link has not been opened. **Opened** marks a link that you already opened; it is not a playback position. If a Playable link reports expiry, its badge can show a value such as **Link valid for 3d 4h** or **Link may have expired**. Expiry is an estimate from the Source; a link past its estimate can still play, so the item stays openable. Open it as usual, and use **Refresh** if playback fails.

<DocSection id="faq">

## FAQ

<DocsFaq question="Does removing a Saved link delete the source media?">
  No. **Remove saved link** removes the URL and its Lynvo data from your
  Library. It does not delete anything from the Source.
</DocsFaq>

<DocsFaq question="Why does the link say it may have expired while it still plays?">
  The badge shows an expiry estimate from the Source, and hosts often keep
  serving past it. The Saved link stays openable either way; **Refresh**
  requests a current Playable link when playback actually fails.
</DocsFaq>
