<DocSection id="what-is-a-plugin">

A Plugin is a Source-specific implementation hosted by a Plugin Server. Where the server carries the protocol, the Plugin carries the Source: it recognizes one site's URLs, fetches the Source's data, and maps that data to Media Nodes.

A Plugin for a self-hosted file index shows the shape of the job. It matches the index's domain, follows the index's authentication rules, reads its folders and files, and returns playable items and unresolved items. Everything protocol-shaped — bearer authentication, request validation, usage enforcement — stays in the [Plugin Server runtime](/developer/what-is-a-plugin-server), so every Plugin follows the same contract.

## What a Plugin owns

- Its stable Plugin ID, display name, version, status, and icon
- Host and path matchers
- Source-specific credentials
- Upstream requests and response parsing
- Playable item, folder, group, and unresolved item creation
- Source-specific errors and test fixtures

What it does not own is just as important. A Plugin implements no bearer authentication, no protocol routes, no global usage enforcement, and no Lynvo interface behavior. Keep those in the runtime.

Register every user-visible Plugin under `extensions.lynvo.plugins` in the [manifest](/developer/manifest). Lynvo reads this catalog to show the Plugin in [Settings](/settings/plugins) and route supported URLs to the Plugin Server.

## How an Extraction flows

One request passes through both layers, server first:

1. Lynvo matches a URL against the Plugin Server manifest
2. Lynvo sends the Extraction request to the Plugin Server
3. The Plugin Server authenticates and validates the request
4. The Plugin Server selects the matching Plugin
5. The Plugin converts the Source response into Media Nodes
6. The Plugin Server validates and returns the protocol response

To go deeper, use the [Extraction reference](/developer/extract) when you replace the generated example, and the [route runtime reference](/developer/hono-routes) for the wiring around your Plugin.
