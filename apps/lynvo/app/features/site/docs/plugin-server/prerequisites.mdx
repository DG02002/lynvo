<DocSection id="prerequisites">

Install Node.js and pnpm before generating the project. You need a Cloudflare
account for deployment and a Lynvo account for the final connection test.

Install or prepare:

- Node.js 26.8.1 or newer
- pnpm 12 or newer
- A Cloudflare account with Wrangler access
- A Lynvo account
- A Source website you are authorized to access and extract

If pnpm is already installed, run `pnpm self-update next-12` to get the latest
pnpm 12 release.

After you install these tools and create the accounts, [generate your Plugin
Server](/docs/plugin-server#generate-the-project).

</DocSection>
