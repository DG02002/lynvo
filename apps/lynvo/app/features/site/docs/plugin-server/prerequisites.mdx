<DocSection id="prerequisites">

Prepare these tools and accounts before generating the Cloudflare Worker project. You need a Cloudflare account to deploy the Worker and a Lynvo account for the final connection test.

Install or prepare:

- Node.js 26.9.0 or newer
- pnpm 12 or newer
- A Cloudflare account with Wrangler access
- A Lynvo account
- A Source website you are authorized to access and extract

To update an existing pnpm installation to the latest pnpm 12 release, run:

<CodeBlock label="Terminal">

```sh
pnpm self-update next-12
```

</CodeBlock>
