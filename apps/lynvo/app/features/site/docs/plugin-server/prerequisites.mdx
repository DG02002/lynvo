<DocSection id="prerequisites">

Building a Custom Plugin Server needs three tools and two accounts. Everything after this page assumes they are ready.

Install or prepare:

- Node.js 26.9.0 or newer
- pnpm 12 or newer
- A Cloudflare account with Wrangler access
- A Lynvo account
- A Source website you are authorized to access and extract

The Cloudflare account deploys the Worker; the Lynvo account connects it at the end of the path. The Source is yours to choose — Lynvo supplies no catalogue, so a Plugin exists to serve URLs you already have permission to access.

To update an existing pnpm installation to the latest pnpm 12 release, run:

<CodeBlock label="Terminal">

```sh
pnpm self-update next-12
```

</CodeBlock>
