<DocSection id="deployment">

Deploy the Worker only after the local [contract checks](/developer/testing) pass and the production Plugin Server API key is configured as a Cloudflare secret.

To sign in to Wrangler and store the production bearer key, run:

<CodeBlock label="Terminal">

```sh
pnpm wrangler login
pnpm wrangler secret put LYNVO_PLUGIN_SERVER_API_KEY
```

</CodeBlock>

To run the checks and deploy the Worker, use:

<CodeBlock label="Terminal">

```sh
pnpm check
pnpm test
pnpm build
pnpm deploy
```

</CodeBlock>

`pnpm build` optimizes Plugin icons and runs a Wrangler dry run; `pnpm deploy` runs the same image pass and creates or updates the Worker.

## Verify the deployment

Call the four required endpoints at the deployed HTTPS origin — `/manifest`, `/verify`, `/usage`, and `/extract`. If the manifest enables discovery, call `POST /discover` too. Confirm the production secret works and the manifest contains only production URLs.

Keep the deployment origin stable after users connect it. Bound upstream requests, reject unsupported hosts, and record structured logs without credentials.

When the deployed origin responds correctly, [connect the Plugin Server to Lynvo](/developer/connect).
