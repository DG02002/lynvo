<DocSection id="usage-schema">

Every connected credential must have at least one finite usage metric. The
Plugin Server must enforce the limits it reports.

Define the response schema:

<CodeBlock label="src/protocol.ts">

```ts {3-11}
import { Schema } from "effect"

export const usageResponseSchema = Schema.Struct({
  metrics: Schema.NonEmptyArray(
    Schema.Struct({
      id: Schema.NonEmptyString,
      label: Schema.NonEmptyString,
      used: Schema.Number.pipe(
        Schema.check(Schema.isNonNegative()),
        Schema.check(Schema.isFinite())
      ),
      limit: Schema.Number.pipe(
        Schema.check(Schema.isPositive()),
        Schema.check(Schema.isFinite())
      ),
      unit: Schema.NonEmptyString,
      period: Schema.Literals(["daily", "monthly"]),
      resetsAt: Schema.String,
      pluginId: Schema.optional(Schema.NonEmptyString),
    })
  ),
})
```

</CodeBlock>

Return one record for each independently enforced limit:

<CodeBlock label="GET /usage">

```json {3-11}
{
  "metrics": [
    {
      "id": "extract-requests",
      "label": "Extract requests",
      "used": 84,
      "limit": 1000,
      "unit": "requests",
      "period": "monthly",
      "resetsAt": "2026-08-01T00:00:00.000Z"
    }
  ]
}
```

</CodeBlock>

Each metric must satisfy these invariants:

- `id` is unique within the response
- `limit` is positive and finite
- `used` is non-negative, finite, and no greater than `limit`
- `period` is `daily` or `monthly`
- `resetsAt` is an ISO 8601 timestamp
- `pluginId` identifies a Plugin-specific allowance

Use a Cloudflare Durable Object for atomic reservations. Reserve capacity before
the adapter performs upstream work. Return `RATE_LIMITED` when no capacity
remains. Settle the reservation after the adapter finishes. Release it when
your accounting policy does not charge failed work.

<DocsNote title="Use the reported limits">

Report the same allowances you enforce. Lynvo renders the metrics returned by
your Plugin Server and does not own third-party accounting.

</DocsNote>
