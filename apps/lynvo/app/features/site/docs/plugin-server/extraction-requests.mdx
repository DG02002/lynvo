<DocSection id="request-schema">

`POST /extract` accepts a Source URL or a lazy-node follow-up request. Reject malformed bodies before the Plugin runs.

<CodeBlock label="src/protocol.ts">

```ts {3-11}
import { Schema } from "effect"

const sourceInput = Schema.Struct({
  kind: Schema.Literal("source"),
  sourceUrl: Schema.String,
})

const nodeInput = Schema.Struct({
  kind: Schema.Literal("node"),
  nodeUrl: Schema.String,
  resourceId: Schema.optional(Schema.String),
})
```

</CodeBlock>

Add optional Plugin selection and credential fields to the request envelope:

<CodeBlock label="src/protocol.ts">

```ts {2,4-8}
export const extractRequestSchema = Schema.Struct({
  input: Schema.Union([sourceInput, nodeInput]),
  pluginId: Schema.optional(Schema.NonEmptyString),
  password: Schema.optional(Schema.String),
  basicAuth: Schema.optional(
    Schema.Struct({
      username: Schema.String,
      password: Schema.String,
    })
  ),
})
```

</CodeBlock>

A Source Extraction request uses `sourceUrl`:

<CodeBlock label="POST /extract">

```json
{
  "input": {
    "kind": "source",
    "sourceUrl": "https://media.example.com/watch/123"
  }
}
```

</CodeBlock>

A lazy follow-up uses the `nodeUrl` returned by the same Plugin Server:

<CodeBlock label="POST /extract">

```json
{
  "pluginId": "example-media",
  "input": {
    "kind": "node",
    "nodeUrl": "https://media.example.com/folders/bonus",
    "resourceId": "bonus_v1"
  }
}
```

</CodeBlock>

</DocSection>
