## Create a Custom Plugin Server

Use the published starter to create a Cloudflare Worker with the protocol runtime, a working example Plugin, and contract tests. You do not need to clone Lynvo or assemble the Worker shell yourself.

<CodeBlock label="Terminal">

```sh
pnpm create lynvo-plugin-server@latest my-lynvo-plugin-server
cd my-lynvo-plugin-server
cp .dev.vars.example .dev.vars
pnpm check
pnpm test
pnpm build
```

</CodeBlock>

Set `LYNVO_PLUGIN_SERVER_API_KEY` in `.dev.vars`, then start the Worker with `pnpm dev`. The generator installs dependencies by default. If you pass `--skip-install`, run `pnpm install` before the checks.

<DocsNote title="The starter owns the protocol shell">

The generated project already wires `/manifest`, `/verify`, `/usage`, and `/extract` through `@dg02002/lynvo-plugin-server-protocol`. Replace the example manifest and Plugin before you connect a production Worker.

</DocsNote>

The starter includes:

- A Hono Cloudflare Worker and Wrangler configuration
- A semver dependency on the published protocol package
- A manifest with one example Plugin
- A shared runtime for authentication, validation, usage, and Extraction
- Contract tests for the manifest, authentication, usage, and Extraction

The example usage response is a finite test fixture. Replace it with durable accounting before production deployment.
