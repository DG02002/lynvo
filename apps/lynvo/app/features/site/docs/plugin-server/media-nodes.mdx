<DocSection id="node-schema">

Media Nodes are the normalized results Lynvo receives from a Plugin. Use this reference with [Extraction request targets](/docs/plugin-server/extraction-requests) and the [successful response envelope](/docs/plugin-server/success-responses).

Plugins return four product-level node types. Protocol version `1.0` represents
them with three `kind` values:

| Product item       | Protocol kind | Required fields                         |
| ------------------ | ------------- | --------------------------------------- |
| Playable item      | `playable`    | `label`, `url`                          |
| Display-only group | `group`       | `label`, `children`                     |
| Selectable folder  | `group`       | `label`, `selectable: true`, `children` |
| Unresolved item    | `resolvable`  | `label`, `nodeUrl` or `resourceId`      |

### Return a playable item

Use `playable` when the URL points directly to a video or audio file. Lynvo can send this URL to the selected media player without another extraction request.

<CodeBlock label="Playable node">

```ts {2,5}
const playableItem = {
  kind: "playable",
  id: "episode-1",
  label: "Episode 1",
  url: "https://cdn.example.com/episode-1.mp4",
  badge: "1080p",
  size: "1.4 GB",
  expiry: 1767225600000,
  status: "up",
}
```

</CodeBlock>

`status` may be `up`, `down`, or `unknown`. `expiry` is an optional Unix timestamp in milliseconds.

### Return a display-only group

Use a non-selectable `group` to label and organize child nodes. A group cannot be selected as a playable item or folder.

<CodeBlock label="Group node">

```ts {2,6}
const seasonGroup = {
  kind: "group",
  id: "season-1",
  label: "Season 1",
  selectable: false,
  children: [playableItem],
}
```

</CodeBlock>

### Return a selectable folder

Set `selectable` to `true` when the group represents a whole folder. The folder
includes its children in the current response.

<CodeBlock label="Folder node">

```ts {2,5}
const selectableFolder = {
  kind: "group",
  id: "all-seasons",
  label: "All seasons",
  selectable: true,
  children: [seasonGroup],
}
```

</CodeBlock>

### Return an unresolved item

Use `resolvable` when loading a folder or playable item requires another request. Include a `nodeUrl`, a `resourceId`, or both. Lynvo sends that identity back to the same Plugin Server when someone opens the item.

<CodeBlock label="Unresolved item node">

```ts {2,6}
const unresolvedItem = {
  kind: "resolvable",
  id: "bonus-content",
  label: "Bonus content",
  badge: "Open folder",
  nodeUrl: "https://media.example.com/folders/bonus",
  resourceId: "bonus_v1",
}
```

</CodeBlock>

The same Plugin Server must resolve every node identity it emits. Never include credentials in `nodeUrl`, `resourceId`, labels, or metadata.
