## Create a Hono Cloudflare Worker

Create a Worker-first Hono project with the canonical Lynvo starter. A Plugin
Server does not need a React frontend.

<CodeBlock label="Terminal">

```sh
pnpm create lynvo-plugin-server@latest my-lynvo-plugin-server

cd my-lynvo-plugin-server
pnpm test
pnpm build
```

</CodeBlock>

The generator includes Wrangler, Hono, the published protocol package, a
minimal example Plugin, and contract tests. Configure Wrangler with a current
compatibility date and Worker observability if your deployment needs it.

<CodeBlock label="wrangler.jsonc">

```jsonc
{
  "$schema": "node_modules/wrangler/config-schema.json",
  "name": "my-lynvo-plugin-server",
  "main": "src/index.ts",
  "compatibility_date": "2026-07-23",
  "observability": {
    "enabled": true,
  },
}
```

</CodeBlock>

Run the generated Worker locally:

<CodeBlock label="Terminal">

```sh
pnpm dev
```

</CodeBlock>

Wrangler prints the local origin. The default is usually `http://localhost:8787`, but you must use the origin shown in your terminal.
