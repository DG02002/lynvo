## Prepare your development environment

Install the tools and create the accounts required for local development and deployment:

- Node.js and pnpm
- A Cloudflare account with Wrangler access
- A Lynvo account for the final connection test
- One source website you are authorized to access and extract

Your Worker must expose a stable HTTPS origin after deployment. It must never require a browser session or browser cookies from Lynvo.
