## Configure bearer authentication

Lynvo sends one Worker API key in the `Authorization` header. Validate it before usage reservation or upstream network work.

Define the Cloudflare environment and a reusable authentication function:

<CodeBlock label="src/auth.ts">

```ts
export interface Env {
  EXTRACTOR_API_KEY: string
}

export const isAuthorized = (request: Request, env: Env): boolean =>
  request.headers.get("Authorization") === `Bearer ${env.EXTRACTOR_API_KEY}`
```

</CodeBlock>

Store the production key as a Cloudflare secret:

<CodeBlock label="Terminal">

```sh
pnpm wrangler secret put EXTRACTOR_API_KEY
```

</CodeBlock>

Use `.dev.vars` for local development. Keep this file out of version control.

<CodeBlock label=".dev.vars">

```dotenv
EXTRACTOR_API_KEY=your_local_extractor_api_key_here
```

</CodeBlock>

The bearer key authenticates Lynvo to your Worker. Source-side HTTP Basic Auth uses the separate `basicAuth` request field.
