## Return a successful extraction response

Every successful extraction returns source metadata, an array of normalized nodes, and an extensions object.

<CodeBlock label="Successful response">

```json {2-7,9-15}
{
  "source": {
    "pluginServerId": "com.example.my-extractor",
    "displayName": "My Extractor",
    "pluginId": "example-media",
    "sourceName": "Example Media",
    "pageTitle": "Example collection"
  },
  "nodes": [
    {
      "kind": "playable",
      "id": "episode-1",
      "label": "Episode 1",
      "url": "https://cdn.example.com/episode-1.mp4"
    }
  ],
  "extensions": {}
}
```

</CodeBlock>

The `source` object supports:

| Field           | Required | Purpose                   |
| --------------- | -------- | ------------------------- |
| `pluginServerId`   | Yes      | Matches the manifest      |
| `displayName`   | Yes      | Extractor display name    |
| `iconUrl`       | No       | Extractor icon            |
| `pluginId`      | No       | Matches a declared source |
| `sourceName`    | No       | Source display name       |
| `sourceIconUrl` | No       | Source icon               |
| `pageTitle`     | No       | Extracted page title      |
| `audio`         | No       | Audio-language summary    |

Lynvo owns layout, watched state, saved selection, playback state, and mirror caching. Do not return UI instructions.
